## 🚀 Quick Start

### View Live
```bash
# Just visit
https://viewunitysystem.github.io/OnAirMulTiMedia/
```

### Run Locally
```bash
# Clone repository
git clone https://github.com/ViewUnitySystem/OnAirMulTiMedia.git
cd OnAirMulTiMedia

# Start local server
python3 -m http.server 8000

# Open browser
http://localhost:8000
```

### Run Tests
```bash
# Install dependencies
npm install

# Run all tests
npm test

# Run specific tests
npm run test:lighthouse
npm run test:accessibility
npm run test:links
```
