✨ Key Features

📊 Audit-Trail System

Immutable event logging with SHA-256 hash chaining. Real-time monitoring via WebSocket. Compliance export for authorities (BNetzA, FCC, etc.).

🏛️ Regulatory Compliance

Germany (BNetzA), EU (RED 2014/53/EU), USA (FCC Part 15/97), Netherlands (Agentschap Telecom), ITU Band Plans.

⏰ Global Meeting Clock

Timezone-synchronized scheduling. Multi-timezone display. Countdown timers. Calendar integration (Google, Outlook).

🎨 Canvas Swipe

Touch-optimized UI/UX. Gesture recognition. Hardware-accelerated animations. 60 FPS performance.

🛡️ RF Validation

License verification. Frequency band validation. Power limit enforcement. Offline operation with cached band plans.

💾 Backup & Recovery

3-2-1 backup strategy. Versioned snapshots. AES-256-GCM encryption. Multiple backends (Local, S3, Mega.nz).

🚀 Quick Start

# Clone repository
git clone https://github.com/ViewunitySystem/OnAirMulTiMedia.git
cd OnAirMulTiMedia

# Install dependencies
npm install

# Build Rust core
cargo build --release

# Run setup
npm run setup

# Start server
npm start
